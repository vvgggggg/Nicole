# 💌 Sorpresa: ¿Quieres ser mi novia?

Página web romántica tipo storytelling, pensada para abrirse desde el celular escaneando un QR.

**Recorrido:** portada → capítulos con fotos tipo polaroid → contador de tiempo juntas →
frasco de razones → sobre que se abre → carta animada → "¿Quieres ser mi novia?" →
(el botón "No" huye 😏) → confeti de corazones.

## ✏️ Personalizar
1. Abre `index.html` y edita solo el bloque `CONFIG` (nombres, fecha, textos, carta, razones).
2. Sube las fotos a la carpeta `fotos/` como `1.jpg`, `2.jpg`, `3.jpg`, `4.jpg`.
3. (Opcional) Sube una canción como `musica.mp3` y pon `musica: "musica.mp3"` en `CONFIG`.

## 🌐 Publicar gratis con GitHub Pages
1. En GitHub: **Settings → Pages**.
2. En *Build and deployment*: Source = **Deploy from a branch**, Branch = **main**, carpeta **/ (root)** → Save.
3. En 1–2 minutos queda en: **https://vvgggggg.github.io/Nicole/**

> El repositorio debe ser **público** para usar Pages gratis.
